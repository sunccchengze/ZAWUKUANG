## 对照原文：覆盖检查

- **开场 / 找目标** → P4：个人经验仅供参考、收获、没白来、非劝卷非劝躺、不必照搬、自己找目标。
- **到校迷茫 / 行动** → P5：老实上课、迷茫探索、独处充电、不合群不是优越、找到节奏、机会不等人、主动＋求助。
- **起初社恐 / 课程背景 / 找据点** → P6–P7：性格内向、起初社恐、不敢进图书馆、宿舍不自在；单独列出多班大课与“只有两机导论是小班授课”，**不把社恐归因于大课**；后续呈现走过的教学楼、iLibrary Space、图书馆根据地和自习环境。
- **别困宿舍 / 朋友** → P8 / P16：身体兴趣宿舍自习、社交圈别局限在一起上课的几个班、信息闭塞、成天打游戏、社团、心灵寄托、好朋友。
- **强基 / 学业** → P9–P10：硕士/直博、数学物理、奔满分、提问题发论文、AI 不替你学、历年真题/作业题/老师 PPT、AI agent 出拔高题/挖坑题。
